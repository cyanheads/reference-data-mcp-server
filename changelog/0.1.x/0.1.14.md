# 0.1.14 — 2026-07-16

## Changed

- **`ref_element_lookup`** — resolves international/IUPAC spellings (Aluminium, Caesium, Sulphur) to their US-spelled dataset entries via a name-alias map, consulted by both the `name` and `auto` lookup branches ([#34](https://github.com/cyanheads/reference-data-mcp-server/issues/34)).
- **`ref_unit_convert`** description — mass units `mt` (metric tonne, 1000 kg) and `t` (US short ton, 907.18 kg) are now individually glossed to prevent silent unit confusion ([#35](https://github.com/cyanheads/reference-data-mcp-server/issues/35)).

## Fixed

- **`ref_timezone_convert`** — rejects out-of-range calendar components (e.g. February 30, month 13, hour 25) that previously rolled over silently to a different date via `Date.UTC()` normalization; the `datetime` field's format constraint is now also enforced by a Zod `.regex()`, advertised in the input schema rather than only in `.describe()` prose ([#32](https://github.com/cyanheads/reference-data-mcp-server/issues/32)).
- **`ref_timezone_convert`** — rejects DST spring-forward-gap datetimes (e.g. `2026-03-08T02:30:00` in `America/New_York`, a wall-clock moment that never occurs) instead of returning a non-invertible UTC equivalent ([#37](https://github.com/cyanheads/reference-data-mcp-server/issues/37)).
- **`ref_constant_lookup`** — name queries (e.g. "Rydberg constant") now report `match_strategy: "exact_name"` instead of `"exact_symbol"`; the case-sensitive index backing the symbol branch no longer holds mixed-case name aliases ([#38](https://github.com/cyanheads/reference-data-mcp-server/issues/38)).
- **README** — corrected the `ref_constant_lookup` dataset size from "~360 entries" to the actual 32, in both the tool section and the feature summary ([#39](https://github.com/cyanheads/reference-data-mcp-server/issues/39)).
