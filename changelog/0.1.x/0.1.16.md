# 0.1.16 — 2026-09-20

## Added

- **Public hosted instance** — added the public Streamable HTTP endpoint (`https://reference-data.caseyjhand.com/mcp`) to README and `server.json` — no installation required.
- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`** — how to file an issue, which layer a bug belongs to, and the conduct terms for project spaces.
- **`bun run audit:fix`** (`bun audit fix`) — the first response to a transitive advisory, ahead of `bun update <name>`, `bun dedupe`, and `audit:refresh`.

## Changed

- **Bun floor raised to `>=1.4.0`** in `package.json` `engines`, the README prerequisites, and `CLAUDE.md`/`AGENTS.md`. Node stays at `>=24.0.0`.
- **Development skills moved from `skills/` to `framework-skills/`** — Claude Code and Codex auto-load a plugin's root `skills/`, so the `.claude-plugin/` install handed these to every agent that installed the server. The agent mirrors (`.claude/skills/`, `.agents/skills/`) keep their names.
- **Tool error `content[0].text` closes with a `(reason <reason>)` term** — `(reason no_match)`, `(reason incompatible_units)` — so a caller can branch on the reason without parsing `structuredContent`. Argument rejections also carry a `Recovery: <hint>` line derived from the schema. `structuredContent` is unchanged.
- **An out-of-schema tool argument is rejected as `InvalidParams` (`-32602`)** carrying `structuredContent.error` with `reason: "invalid_arguments"`, where the rejection previously surfaced as a bare error text block.
- **`sessionMode: 'stateless'` is declared in `src/index.ts`** — the posture lives in source rather than only in `MCP_SESSION_MODE`, which still wins when it carries a meaningful value.
- **`package.json` `files` ships `changelog/` and `AGENTS.md`**, so the per-version release notes and the agent protocol travel with the published package.
