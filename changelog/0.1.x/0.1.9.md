# 0.1.9 — 2026-06-04

## Fixed

- **`ref_unit_convert`** `from`/`to` `.describe()` examples updated: `mph` → `m/h`, `BTU` → `kJ` (both were unrecognized by `convert-units`). Error recovery hint for `unknown_unit` updated to match ([#25](https://github.com/cyanheads/reference-data-mcp-server/issues/25)).
- **`TimezoneService.convert()`** unreachable `isValidIana` guards removed — handler pre-validates timezone IDs and datetime format before delegating, making these throws dead code with mismatched error contracts ([#26](https://github.com/cyanheads/reference-data-mcp-server/issues/26)).
