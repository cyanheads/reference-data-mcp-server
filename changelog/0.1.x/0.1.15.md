# 0.1.15 — 2026-08-24

## Added

- **Public cache hints** — tool, resource, template, and discovery listings advertise a one-hour shared cache; country and element resources advertise 24 hours, while timezone resources advertise 60 seconds.
- **Recovery hints** — declared tool failures now include action-specific next steps in client error payloads.

## Changed

- **Tool wire contracts** — unknown top-level input properties are now rejected before handlers run, and declared output schemas advertise the structured error responses clients already receive.
- **HTTP compatibility** — HTTP endpoints serve MCP protocol revision 2026-07-28 alongside legacy clients.
- **Session mode** — `.env.example`, the Docker image, and README now explicitly select stateless serving; the documented `auto` option resolves to stateful.
- **Validation semantics** — invalid timezone resource parameters now use `ValidationError`, and the design document matches the framework error contract.
- **Bun 1.4 and multi-architecture Docker builds** — both image stages use Bun 1.4.0, the build stage follows the target platform, and production installs omit development and optional peer packages plus lifecycle scripts.
- **TypeScript and tests** — TypeScript 7 now drives builds and typechecks the test suite; shared assertions keep migrated framework-context tests type-safe.
- **Framework maintenance assets** — project scripts and framework skills are synced through `@cyanheads/mcp-ts-core` 0.12.3, including portable MCPB cleanup and current definition, packaging, dependency, and docs gates.
- **Security contact** — public vulnerability reports continue to route to `security@caseyjhand.com`.
