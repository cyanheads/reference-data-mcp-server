# 0.1.17 — 2026-10-09

## Added

- **`scripts/install-otel.ts` and `scripts/prune-musl-packages.ts`** — build-time scripts the Dockerfile `deps` stage runs (see Docker image below).

## Changed

- **Tool error results carry `data.requestId`**, and their text closes with `request <id>` (mcp-ts-core 0.13.10, [cyanheads/mcp-ts-core#576](https://github.com/cyanheads/mcp-ts-core/issues/576)).
- **Arguments are repaired before validation.** A numeric string sent to a number field is accepted as the number (`value` on `ref_unit_convert`, `limit` on `ref_geo_search`, `period` on `ref_element_search`), and `null` at an optional key is treated as absent (0.13.14, [cyanheads/mcp-ts-core#707](https://github.com/cyanheads/mcp-ts-core/issues/707), [cyanheads/mcp-ts-core#616](https://github.com/cyanheads/mcp-ts-core/issues/616)). An integer sent to a string field is accepted as its digits, e.g. `ref_http_status` with `query: 404` (0.13.9, [cyanheads/mcp-ts-core#487](https://github.com/cyanheads/mcp-ts-core/issues/487)). A boolean sent to a number field is still rejected with `-32602`.
- **MCP SDK 2.1 transport behavior** (0.13.9). Over HTTP, a 2026-07-28 POST without `MCP-Protocol-Version` is refused with `400` / `-32020`, and a JSON-RPC batch of more than 100 messages is refused whole. On stdio, stdin EOF aborts requests still in flight.
- **`server.json` MCP Registry entries** — the npm package entries drop the `run start:*` arguments and set `runtimeHint: "npx"`, and the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `"http"`, so a registry client launching that entry gets the HTTP transport (0.13.11, [cyanheads/mcp-ts-core#622](https://github.com/cyanheads/mcp-ts-core/issues/622)).
- **Tool handlers no longer pass `ctx.recoveryFor(...)` explicitly.** The framework fills each declared recovery hint from the `errors[]` contract (0.13.10, [cyanheads/mcp-ts-core#579](https://github.com/cyanheads/mcp-ts-core/issues/579)); the hints callers receive are unchanged. The change removes duplicated code.
- **`ref_unit_convert`'s unreachable fallback throws `internalError`** instead of a plain `Error`: the same `-32603` on the wire, and it satisfies the framework's `prefer-mcp-error-in-handler` lint rule.
- **Docker image**:
  - Production dependencies install in a `deps` stage on the build platform and cross-install per target architecture, so multi-arch builds no longer run Bun under emulation (0.13.10, [cyanheads/mcp-ts-core#575](https://github.com/cyanheads/mcp-ts-core/issues/575)).
  - OpenTelemetry packages install at the framework's declared ranges via `scripts/install-otel.ts` (0.13.10, [cyanheads/mcp-ts-core#578](https://github.com/cyanheads/mcp-ts-core/issues/578)).
  - musl-only packages are pruned from the glibc image (0.13.11, [cyanheads/mcp-ts-core#608](https://github.com/cyanheads/mcp-ts-core/issues/608)).
  - The base image is `oven/bun:1.4.2` (`packageManager` is `bun@1.4.2`); the unused `MCP_FORCE_CONSOLE_LOGGING` env var is removed; the Dockerfile creates writable `.cache` and `.mirror` directories for the `bun` user.
- **CodeQL workflow runs one job per language** (`actions`, `javascript-typescript`), each uploading under its `/language:<language>` category.
- **Ignore files**: `.gitignore` and `.dockerignore` cover every `.env*` file (`.gitignore` keeps `.env.example`, `.env.template`, `.env.sample`), `.dockerignore` also excludes the MCP Registry token files, and `.mcpbignore` excludes `docs/idea.md`, `logs/`, `.cache/`, `coverage/`, and `tests/` from the bundle.
- **`package.json`** — `files` excludes `dist/*.mcpb`, and `rebuild` runs `scripts/build.ts` directly.
- **`.env.example`** matches the framework template: `MCP_HTTP_HOST` default `127.0.0.1`, plus the request-state, SSE resumability, log rate-limit, failure-payload, and OTLP endpoint variables.
- **`devcheck.config.json`** — the `outdated` allowlist is empty and a `lint` block is added.
- **Framework skills and scripts resynced** to mcp-ts-core 0.13.14: `framework-skills/`, plus `scripts/devcheck.ts`, `lint-mcp.ts`, `lint-packaging.ts`, `check-skill-versions.ts`, `check-framework-antipatterns.ts`, and `release-github.ts`.
- **`CLAUDE.md` and `AGENTS.md`** updated to the framework template (framework `^0.13.14`, MCP SDK `^2.2.0`, resource count, server identity and session-posture sections, `ctx` table, error-contract text). The README badges show MCP SDK `^2.2.0` and Bun `v1.4.2`; the `CITATION.cff` abstract drops its em dash.
