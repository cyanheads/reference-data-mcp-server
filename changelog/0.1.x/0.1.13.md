# 0.1.13 — 2026-07-16

Framework adoption with install-time supply-chain hardening, plus a batch of reference-data correctness fixes.

## Added

- **`@socketsecurity/bun-security-scanner`** — Bun `[install.security]` scanner that vets every package for malware, typosquats, and known CVEs before install; added to `trustedDependencies`.
- **`bunfig.toml` `minimumReleaseAge`** — blocks package versions published under 3 days ago (guard against freshly compromised releases); `@cyanheads/mcp-ts-core` is excluded so first-party framework releases stay same-day.
- **`.github/SECURITY.md`** — vulnerability disclosure policy (private GitHub advisory or casey@caseyjhand.com).
- **`.gitattributes`** — LF normalization, binary-asset guards, and `linguist-generated` on `bun.lock`, `CHANGELOG.md`, `docs/tree.md`.

## Changed

- **`Dockerfile`** — base image pinned `oven/bun:1.3` → `oven/bun:1.3.14`; build stage gains `--ignore-scripts`; BuildKit cache mounts on every install layer.
- **`ref_constant_lookup` relatedness** — `related[]` now scores whole-token overlap on the constant name only (lowercased, split on non-alphanumerics, tokens ≥ 3 chars, stopwords dropped); symbols and aliases are excluded to kill 1–2-char substring false positives, and an empty result is preferred over noise ([#33](https://github.com/cyanheads/reference-data-mcp-server/issues/33)).
- **`packageManager`** `bun@1.3.11` → `bun@1.3.14`; `package.json` `author` refreshed to `Casey Hand <casey@caseyjhand.com> (https://caseyjhand.com)`.

## Fixed

- **HTTP status cacheability** — `cacheable` flags corrected to the RFC 9110 §15.1 heuristically-cacheable set: `204`/`405` → `true`, `304`/`226` → `false` ([#29](https://github.com/cyanheads/reference-data-mcp-server/issues/29)).
- **United Kingdom ccTLD** — `ref_geo_lookup` returns `.uk` (not `.gb`) for `GB`, the only country whose TLD diverges from its lowercased ISO alpha-2 code ([#30](https://github.com/cyanheads/reference-data-mcp-server/issues/30)).
- **Molar volume of ideal gas (STP)** — value corrected to `0.02241396954` m³ mol⁻¹ with label `exact (at 273.15 K, 101.325 kPa / 1 atm)` (CODATA 2022, 1 atm reference) ([#31](https://github.com/cyanheads/reference-data-mcp-server/issues/31)).
- **`constant` relatedness collisions** — the domain-generic `constant` token (in ~14 of 32 names) is now a stopword, so unrelated `X constant` entries no longer relate on that word alone; genuine token relations (Planck ↔ reduced Planck, molar gas ↔ molar volume) survive ([#36](https://github.com/cyanheads/reference-data-mcp-server/issues/36)).
- **`src/data/` tracking** — the `.gitignore` `data/` pattern was anchored to `/data/`; unanchored, it had been silently ignoring `src/data/` (`http-status-codes.ts`, `periodic-table.ts`, `physical-constants.ts`), which are now tracked and carry the #29/#31 corrections.
- **`.github/FUNDING.yml`** — trimmed scaffold placeholder platforms; keeps `github` and `buy_me_a_coffee`.
