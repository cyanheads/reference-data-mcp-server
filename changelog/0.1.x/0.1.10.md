# 0.1.10 — 2026-06-12

## Added

- **Dockerfile** `HEALTHCHECK` polling `/healthz` every 30s, plus an `org.opencontainers.image.version` OCI label sourced from a new `APP_VERSION` build arg.
- **`scripts/clean-mcpb.ts`** strips dev-only files from the packed `.mcpb`; chained into the `bundle` script after `mcpb pack`.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.21` → `^0.10.6`.
- **`createApp()`** sets explicit `name` and `title` (`reference-data-mcp-server`) instead of relying on the scoped-package name fallback.
- **Error contracts** `ref_timezone_convert` (`invalid_timezone`, `invalid_datetime`), `ref_timezone_lookup` (`invalid_at`), and `ref_unit_convert` (`unknown_unit`) reclassified from `JsonRpcErrorCode.InvalidParams` to `JsonRpcErrorCode.ValidationError`.
- **`.mcpbignore`** patterns anchored with leading `/`; `.agents/` and `skills/` added to the exclude set.
- **`scripts/check-framework-antipatterns.ts`** adds a `coerce-boolean-env-flag` rule (flags `z.coerce.boolean()` on env flags — use `z.stringbool()`) and now skips comment lines so JSDoc naming a pattern isn't a false positive.
- **Skills** synced from the framework scaffold; `skills/techniques/` added.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.21 → ^0.10.6
- `@types/node` ^25.9.1 → ^25.9.3
- `typescript` ^6.0.3 → ^5.9.3
- `vitest` ^4.1.7 → ^4.1.8
