# 0.1.12 — 2026-06-20

Framework maintenance only — no server source or behavior changes.

## Added

- **`scripts/check-dependency-specifiers.ts`** — devcheck step (`Dependency Specifiers`, `--no-dep-specifiers`) that hard-fails on floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json`'s dependency sections and `bun.lock`'s `workspaces` map, catching a stray `latest` dist-tag before the next `bun install` re-resolves a dep past its range or hold (cyanheads/mcp-ts-core#246).
- **Plugin marketplace manifest checks** in `scripts/lint-packaging.ts` — validates `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json` for non-empty descriptions, unscoped display names, and a full-name `npx -y` install arg; gated by the new `devcheck.config.json` `packaging.pluginManifests` flag (cyanheads/mcp-ts-core#240).

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.10.6` → `^0.10.9`.
- **`scripts/devcheck.ts`** registers the `Dependency Specifiers` check and guards the git-dependent steps (TODOs/FIXMEs, Tracked Secrets, Framework Antipatterns) behind a shared `isGitRepo()` check so a fresh scaffold no longer reports `git`'s exit 128 as a failure (cyanheads/mcp-ts-core#243).
- **`scripts/build-changelog.ts`** exits cleanly under `--check` when no `<major.minor>.x/` version files exist yet (cyanheads/mcp-ts-core#242).
- **`scripts/check-framework-antipatterns.ts`** self-guards outside a git repo when invoked directly (cyanheads/mcp-ts-core#243).
- **`scripts/check-skill-versions.ts`** skips a `SKILL.md` deleted from the worktree instead of crashing with `ENOENT` (cyanheads/mcp-ts-core#237).
- **Skills** — 13 project skills synced from the framework scaffold (`metadata.version` bumps carrying body drift), including the seven re-versioned pre-0.9.18 skills (cyanheads/mcp-ts-core#238) and `git-wrapup`/`orchestrations` v1.4.
