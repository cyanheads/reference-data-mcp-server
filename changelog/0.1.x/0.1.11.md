# 0.1.11 — 2026-06-15

## Added

- **`ref_constant_lookup`** output gains `match_strategy` (`exact_symbol` | `exact_name` | `fuzzy`) reporting which lookup path resolved the constant, rendered as a `**Match:**` line in `format()` with a caution annotation on `fuzzy` ([#27](https://github.com/cyanheads/reference-data-mcp-server/issues/27)).
- **`ref_geo_lookup`** gains an `enrichment` block whose `notice` fires only on a fuzzy name match (starts-with/contains fallback), echoing the query and resolved country so the caller can normalize follow-up lookups ([#27](https://github.com/cyanheads/reference-data-mcp-server/issues/27)).

## Changed

- **`ConstantResult`** widened with `match_strategy`; new exported `MatchStrategy` type. `ConstantsService.buildResult()` takes the strategy per path (case-sensitive symbol → `exact_symbol`, case-insensitive alias → `exact_name`, partial scan → `fuzzy`).
- **`GeoService.lookup()`** return widened to `{ record, fuzzy } | 'numeric_unsupported' | undefined`; code-path lookups are always `fuzzy: false`. Public `lookupByName()` keeps its prior signature.
- **`release:github`** script runner `tsx` → `bun run`.

## Dependencies

- `@biomejs/biome` ^2.4.16 → ^2.5.0
- `vitest` ^4.1.8 → ^4.1.9
