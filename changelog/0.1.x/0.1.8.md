# 0.1.8 — 2026-06-02

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.16` → `^0.9.21` — HTTP transport now carries fresh request + trace/span IDs on each request log (fixes frozen boot-context bleed); `fetchWithTimeout` strips query-string secrets (e.g. `?api_key=`) from error messages and logs; `withRetry` fails fast on non-retryable errors; `ctx.fail` auto-populates the `retryable` flag.
- **README** client-config server key normalized to full package name (`@cyanheads/reference-data-mcp-server`); `args` updated to scoped package identifier.
- **Skills** synced from framework: `add-tool`, `add-service`, `api-canvas`, `api-context`, `api-linter`, `api-utils`, `design-mcp-server`, `release-and-publish` updated; `api-mirror` and `orchestrations` added.
- **`scripts/release-github.ts`** and **`scripts/check-skill-versions.ts`** added from framework scaffold.
- **`CLAUDE.md`** / **`AGENTS.md`** skill table updated with `api-mirror`, `orchestrations` entries and `format:unsafe` command row.
