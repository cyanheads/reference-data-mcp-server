# 0.2.0 — 2026-10-28

## Added

- Publish `reference-data-guide` as an MCP resource for country and timezone scheduling workflows.
- **Agent Skills delivery** includes the guide in plugin installs, npm, Docker, and desktop bundles, with MCP Skills discovery and reads.
- **Agent Plugins 1.0.0** root `plugin.json` and `mcp.json` support plugin discovery alongside the existing client overlays.

## Changed

- **Desktop bundles** exclude root development paths, dependency build-only files, and node-gyp output while preserving SDK skill runtime modules.
- **Development tooling** syncs framework skills, packaging validation, and the bug-report Environment table; dependency minimum release age becomes one day.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.13.16 → ^0.13.18. HTTP requests no longer retain their abort signals after responses end, adopting the fix from mcp-ts-core 0.13.17 ([cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)).
- `@biomejs/biome` ^2.6.2 → ^2.6.3
- `ignore` ^7.0.13 → ^7.0.14
- `tsc-alias` ^1.9.8 → ^1.9.9
